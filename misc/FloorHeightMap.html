FloorHeightMap

Class

FloorHeightMap bakes a mesh's surface into a flat 2D grid of heights, so you can ask "how high is the ground at X, Z" afterwards with a cheap array lookup instead of a real RayCast against actual geometry every time you need an answer.

When To Use It

This is built for one specific use case : a large, roughly continuous terrain/landscape, where you need to query height at a lot of positions, often every frame, placing procedural props or snapping something to the ground. Sampling a heightmap is essentially free compared to casting a ray at every single one of those positions.

It's a poor fit the moment your terrain has more than one surface stacked at the same X, Z position, a bridge over a floor, a tunnel or a cave with a ceiling and a floor at different height. The grid stores exactly one height per cell, whichever surface happens to be highest there, anything underneath is silently ignored and unreachable through Sample(). For anything like that, use RayCast against real Colliders instead.

Building and Sampling

BuildHeightmapFromMesh() reads a GameObject's mesh once and produces a grid covering its footprint, at the specified resolution. Note that it's a bake, if the source mesh moves or changes afterwards, the heightmap doesn't know, you'd need to build a new one.

Sample(x, y) then returns the interpolated height at a given horizontal position (or NegativeInfinity if that position falls outside the baked area or inside but never touched any triangle. Always check for that before trusting a result).

Despite the parameter names, Sample(x, y) takes world X and world Z, not X and Y. The height is what the method returns, not something you pass in.
Call BuildHeightmapFromMesh() from Start(), not Added(). A GameObject's MeshRenderer only gets its actual Model built during Start(), calling this any earlier means GetMesh() is still null and you'll get null back. Start order between different GameObjects also isn't guaranteed, so if your terrain and whatever builds the heightmap are on separate GameObjects, the safest place to bake it is in the terrain's own Start(), or somewhere you can be sure the terrain has already started.
Baking and sampling a heightmap 
//Bake once, typically when the scene starts
FloorHeightMap terrainHeight = FloorHeightMap.BuildHeightmapFromMesh(terrain, 512, 512);

//Later, snap something to the ground at a given X, Z
float groundY = terrainHeight.Sample(worldX, worldZ);
if (!float.IsNegativeInfinity(groundY))
    prop.transform.SetPosition(new Vector3(worldX, groundY, worldZ));
