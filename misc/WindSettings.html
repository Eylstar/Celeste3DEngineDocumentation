WindSettings

Class

WindSettings holds everything that controls how wind sways objects in the Scene, direction, strength and frequency. Every Scene3D has one, you can get it with Scene3D.GetWindSettings() and reapply your changes with Scene3D.SetWindSettings().

Getting and applying WindSettings 
//Get the current WindSettings and reassign it to the scene
WindSettings wind = myScene.GetWindSettings();
wind.strength = 0.2f;
myScene.SetWindSettings(wind);

Direction

Wind only ever blows horizontally, there's no pitch or roll to it, just a direction in the XZ plane.
direction is by default, (1, 0, 0).

Setting this vector by hand works, but it's easier to use SetWindDirectionYaw(), which takes a single angle in degrees around the Y axis.

Wind direction example 
//Wind blowing from the east
wind.SetWindDirectionYaw(90f);

//Setting the direction directly instead
wind.direction = new Vector3(0.7f, 0f, 0.7f);

Strength and Frequency

strength controls how far objects sway, higher values give a bigger, more obvious motion. frequency controls how fast that motion oscillates, higher values make the wind feel gustier and more nervous, lower values give a slow, heavy sway.

Both apply to the whole Scene at once, every GameObject with wind enabled reacts to the same strength and frequency.

Enabling Wind Per Object

Wind is option togglable per object. Set useWind to true on a MeshRenderer for it to sway, MeshRender by defaulthas this setting to false.

On the same MeshRenderer, windMultiplier allows a single object to react more or less than the rest of the Scene without touching the global strength, a tall thin plant swaying more than a short bush for example, while both still follow the same direction and frequency.

Enabling wind on a model 
MeshRenderer bushRenderer = bush.GetComponent<MeshRenderer>();
bushRenderer.useWind = true;
bushRenderer.windMultiplier = 1.5f; //Sways 50% more than the Scene's base strength
How much a vertex sways is weighted by its height within the model, the base stays still, the top moves the most. This height is found out automatically from the model vertices, which assumes each object is a single, individual part. If you merge many separate plants into one big mesh for performance, the per vertex height stops lining up with any single plant and the wind can look wrong, some parts barely moving while others across the same merged mesh sway far too much.

Properties

Property Type Description
direction Vector3 Horizontal direction the wind blows towards, default (1, 0, 0)
strength float How far objects sway, default 1
frequency float How fast the sway oscillates, default 0.5

Methods

Method Return type Description
SetWindDirectionYaw(float yawDegrees) void Sets direction from a single yaw angle in degrees, keeping the wind strictly horizontal
