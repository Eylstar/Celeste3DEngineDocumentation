Camera3D

Class Inherits from GameObject

Camera3D inherits from GameObject, so it has a Transform, a name, and works like any other object in the Scene. What sets it apart is that it computes its view and projection matrices every frame.

Adding a Camera3D to the scene isn't enough on its own to render anything through it, you also need to set it as the active one with Scene3D.SetMainCamera().

If no camera was set before the scene loads, the Scene creates a default one itself.

Basic Camera3D usage 
//Create a camera with a 90° FOV and set it as main
Camera3D cam = new Camera3D(new Vector3(0f, 10f, 5f), Vector3.Zero, 90f);
myScene.AddGameObject(cam);
myScene.SetMainCamera(cam);

//FOV is always in degrees
cam.FOV = 75f;

//Move and rotate it like any other GameObject
cam.transform.SetPosition(new Vector3(0f, 12f, 8f));
cam.transform.LookAt(Vector3.Zero);
Only one Camera3D can be set as MainCamera, but the scene can contains as many cameras as you want. Swapping at runtime beetween multiple Camera3D can be useful to switch beetween different point of views / create cinematics.

Constructors

Declaration Description
Camera3D() Creates a Camera at the origin with no rotation, using the default FOV, Near and Far values
Camera3D(Vector3 position, Vector3 rotation, string name = "") Creates a Camera at the given position and rotation, using Euler angles in degrees, with the default FOV, Near and Far values
Camera3D(Vector3 position, Vector3 rotation, float FOV, string name = "") Creates a Camera with position, rotation in Euler angles in degrees, and an explicit FOV in degrees, using the default Near and Far values
Camera3D(Vector3 position, Vector3 rotationEuler, float FOV = 60f, float Near = 0.1f, float Far = 500f, string name = "") Creates a Camera with position, rotation in Euler angles in degrees, and explicit FOV in degrees, Near and Far planes

Properties

Property Type Description
FOV float Field of view, in degrees
Near float Near clipping plane
Far float Far clipping plane
AspectRatio float Aspect ratio of the game viewport, Width divided by Height, follows the window automatically and can't be set
