DebugDrawShapes3D

Class Static

DebugDrawShapes3D is a static utility class for drawing wireframe shapes directly in 3D space (boxes, spheres and lines). It's what BoxCollider3D and SphereCollider3D use internally for their own DrawShapeDebug(), and what a custom Collider3D should use too, see the Collider3D page for an example.
It's public, so you can also call it yourself for your own debug visuals, outside of a Collider entirely.

Every method takes a Camera3D, used to build the view and projection matrices for that one draw call, and every coordinate you pass in is expected in world space.

These draw immediately to whatever render target is currently active, they aren't batched or deferred. Call them from Render(), the same phase the Engine's own debug drawing uses, not from Update(), where the active render target isn't guaranteed to be the right one yet.
Drawing your own debug shapes 
public class PatrolPathDebug : Behaviour
{
    public Vector3 pointA, pointB;

    public override void Render()
    {
        base.Render();
        Camera3D cam = scene.GetRenderingCamera();

        //A line between two patrol points, and a sphere marking each end
        DebugDrawShapes3D.DrawLine(pointA, pointB, cam, Color.Yellow);
        DebugDrawShapes3D.DrawSphere(pointA, 0.2f, cam, Color.Yellow);
        DebugDrawShapes3D.DrawSphere(pointB, 0.2f, cam, Color.Yellow);

        //A box marking a trigger zone, rotated 45° around Y
        Quaternion rot = Quaternion.CreateFromAxisAngle(Vector3.Up, MathHelper.ToRadians(45f));
        DebugDrawShapes3D.DrawBox(new Vector3(0f, 1f, 0f), new Vector3(2f, 1f, 2f), rot, cam, Color.Cyan);
    }
}

Methods

Method Return type Description
DrawBox(Vector3 center, Vector3 size, Quaternion rotation, Camera3D cam, Color color) static void Draws a wireframe box, center in world space
DrawSphere(Vector3 center, float radius, Camera3D cam, Color color) static void Draws a wireframe sphere, (three circles around the center, one per axis)
DrawLine(Vector3 start, Vector3 end, Camera3D cam, Color color) static void Draws a single line between two world space points
