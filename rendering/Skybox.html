Skybox

Class Inherits from GameObject

Skybox is the GameObject that renders the sky of the scene, using a default sky texture. Every Scene3D creates and manages its own automatically when it loads, its constructor is internal, so you never create one yourself. You control it with Scene3D.EnableSkybox() and Scene3D.ChangeSkyBox().

Calling Destroy() on the Skybox does nothing, it just logs a warning. Use Scene3D.EnableSkybox(false) instead if you want to hide it.

By default the Skybox renders as part of the World pass, alongside your regular World layer models. Setting foregroundRendererEnabled to true makes it render as part of the Foreground pass instead. Check the MeshRenderer and Renderer3D page for how these two passes fit into the rendering pipeline.

Basic Skybox usage 
//Disable the skybox entirely
myScene.EnableSkybox(false);

//Change its texture
myScene.ChangeSkyBox("night_sky");

//Get the Skybox itself to change its render pass
Celeste3DEngine.Skybox sky = myScene.GetSkybox;
sky.foregroundRendererEnabled = true;

Skybox Texture's Cubemap

The Skybox isn't a special rendering mode, it's a regular cube model with a huge scale and fixed on the main rendering Camera3D position, rendered with a single flat texture like any other MeshRenderer, but inside out. The SkyBox texture is just one texture laid out to wrap around all six faces of that cube, the same way you'd unfold a cardboard box flat before folding it back up.

You can go see the default SkyBox texture directly in the Engine mod content, at Graphics/3DEngine/DefaultTextures/sky.png.

Whatever texture you pass to ChangeSkyBox() has to follow that exact same layout, each of the six faces in the same position and orientation the default sky texture uses, or the sky will look broken with seams in the wrong place.

The six sided net a skybox texture needs to follow

There's two practical ways to get a texture in this layout. Plenty of free online downloadable skybox cubemaps already exists. Also, tools that convert a 360° panorama or an HDRI into a six sided cross layout automatically, or even procedurally generates ones also are easy to find. The other option is building the net yourself, painting or compositing each of the six faces directly following the template above.

Properties

Property Type Description
foregroundRendererEnabled bool Whether the Skybox renders as part of the Foreground pass instead of the World pass, default false
