RayCast

Class Static

RayCast is a static utility class useful for casting a ray against every Collider3D in the current Scene. It goes through the same spatial hash grid CollisionSystem uses for regular collision checks, walking through the cells the ray actually passes through instead of testing every Collider in the scene.

A RayCast is a straight line starting at an origin point and going in one direction, capped at whatever max distance you give it. Casting it finds the closest Collider surface it crosses along that line, if any, and tells you exactly where and at what angle. It's a probe, not a physical object, it doesn't push anything and nothing pushes back against it. You can use a Ray struct to store the origin, direction and max distance together if you want to keep track of rays yourself (see Ray below).

Using a RayCast can be extremely useful for cases like ground checks, aiming/shooting, or interacting with objects in front of you.

More information about the values and usages of the hit in the RaycastHit page.

Basic RayCast usage 
//A simple ground check from the player's feet
Vector3 origin = player.transform.Position + new Vector3(0f, 0.1f, 0f);
bool grounded = RayCast.Cast(origin, Vector3.Down, 0.3f, out RaycastHit hit);

//Checking what's 3 units directly in front of the player including triggers
if (RayCast.Cast(player.transform.Position, player.transform.Forward,
                3f, out RaycastHit forwardHit, ignoreTriggers: false))
{
    Logger.Info("Game", $"{forwardHit.Collider.gameObject.name} is {forwardHit.Distance} units ahead");
}
direction is normalized automatically inside Cast, you don't need to do it yourself. Every call is also stored for that frame's debug drawing, if Scene3D.debugShowRayCasts is true you'll see the ray and its hit point drawn.

Methods

Method Return type Description
Cast(Ray ray, out RaycastHit hitInfo, bool ignoreTriggers = true) bool Casts a ray using a Ray, returns true and fills hitInfo with the closest hit found within maxDistance, ignores trigger Colliders by default
Cast(Vector3 origin, Vector3 direction, float maxDistance, out RaycastHit hitInfo, bool ignoreTriggers = true) bool Casts a ray using an origin, direction and distance, returns true and fills hitInfo with the closest hit found within maxDistance, ignores trigger Colliders by default

Ray

Struct

A simple struct that stores an origin, direction and max distance. It can be reused to cast rays without typing all the parameters in the function call;

Basic Ray usage 
//Ray creation
Vector3 origin = player.transform.Position + new Vector3(0f, 1.75f, 0f);
Vector3 direction = player.transform.Forward;
float distance = 5f;

Ray ray = new Ray(origin, direction, distance);

//Firing different RayCasts with the same Ray data
while (player.isMoving)
    RayCast.Cast(ray, out RaycastHit hitInfo);
