SphereCollider3D

Class Inherits from Collider3D Component

SphereCollider3D is a spherical collision shape, good for pickups, simple obstacles, or for anything roughly round. radius is scaled by the largest of the GameObject's Transform scale axes, so a non uniformly scaled object still gets a true sphere rather than an ellipsoid.

Basic SphereCollider3D usage 
//A pickup, trigger only, no physical blocking
GameObject coin = new GameObject("Coin");
SphereCollider3D pickup = new SphereCollider3D(0.5f, Vector3.Zero, isTrigger: true);
coin.AddComponent(pickup);

pickup.onTriggerEnter += det =>
{
    Logger.Info("Game", $"{det.gameObject.name} picked up the coin");
    coin.Destroy();
};

//A solid pillar, blocks anything that touches it
GameObject pillar = new GameObject("Pillar");
pillar.AddComponent(new SphereCollider3D(1.2f, new Vector3(0f, 2f, 0f)));
myScene.AddGameObject(pillar);
