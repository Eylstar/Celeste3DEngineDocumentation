BoxCollider3D

Class Inherits from Collider3D Component

BoxCollider3D is a rectangular collision shape, good for walls, floors, crates, anything box shaped. size is the full box dimensions, not a half size, and it's scaled by the GameObject's Transform scale like everything else.

rotation adds an extra rotation on top of the GameObject's own, in the box's own local space. This lets you angle the box independently from the rest of the object, a tilted collision ramp under a flat looking mesh, or a box that doesn't need to match the model's own orientation at all.

Basic BoxCollider3D usage 
//A flat floor, no rotation needed
GameObject floor = new GameObject("Floor");
floor.AddComponent(new BoxCollider3D(new Vector3(20f, 1f, 20f), Vector3.Zero));

//A wall rotated 90° around Y, using the float overload
GameObject wall = new GameObject("Wall");
wall.AddComponent(new BoxCollider3D(new Vector3(10f, 4f, 1f), Vector3.Zero, rotation: 90f));

//A tilted ramp
GameObject ramp = new GameObject("Ramp");
BoxCollider3D rampCollider = new BoxCollider3D(new Vector3(6f, 0.5f, 10f), Vector3.Zero);
rampCollider.rotation = new Vector3(20f, 0f, 0f);
ramp.AddComponent(rampCollider);

//Resizing at runtime works immediately
rampCollider.size = new Vector3(8f, 0.5f, 12f);

Constructors

Declaration Description
BoxCollider3D(Vector3 size, Vector3 center, float rotation = 0f, bool isTrigger = false, bool enabled = true) Creates a box with a single rotation around the Y axis, in degrees
BoxCollider3D(Vector3 size, Vector3 center, Vector3 rotation, bool isTrigger = false, bool enabled = true) Creates a box with rotation on all three axes with Euler angles in degrees

Properties

Property Type Description
size Vector3 Full dimensions of the box in local space, not a half size, changing it takes effect automatically
rotation Vector3 Extra rotation of the box in its own local space in Euler angles
