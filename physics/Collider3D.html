Collider3D

Class Abstract Component

Collider3D is the abstract base class for every collider shape in the Engine. See the CollisionSystem page for how it ties together with CollisionDetector. A Collider doesn't do anything on its own each frame, it's a static shape sitting at a position, it's the GameObject's Transform, and a CenterOffset if needed, that decides where that shape actually sits in the world.

The Engine ships two ready to use shapes, BoxCollider3D and SphereCollider3D. A GameObject can hold more than one Collider3D at once, each checked independently, a solid body and a larger trigger zone around it, for example.

The Engine also comes with a pre-made solution for large and "hilly/natural" terrain.

Solid vs Trigger

Every Collider3D is either solid or a trigger, controlled by isTrigger, and that flag decides which of its methods actually run each frame and what happens when something overlaps it.

A solid Collider physically blocks any detector's object from going through. Every frame, any CollisionDetector found within range gets tested with CheckCollision, and if it's currently penetrating the shape, its GameObject is pushed back out immediately, corrected before that frame finishes. onCollision only fires when an actual push happened.

A trigger Collider never pushes anything, nothing physically stops a Detector from walking straight through it. Instead it's tested with CheckOverlap every frame, and onTriggerEnter, onTriggerStay and onTriggerExit fire depending on whether that test just became true, stayed true, or just became false. Use triggers for zones, pickups, checkpoints, anything that should react to something entering or leaving a space without physically stopping it.

Because of this split, a solid Collider will never fire onTriggerEnter, onTriggerStay or onTriggerExit no matter what you subscribe to them, and a trigger Collider will never fire onCollision. Subscribe to whichever pair of events actually matches the Collider's isTrigger value.

Solid vs trigger, side by side 
//Solid, physically stops anything that touches it, fires onCollision
GameObject wall = new GameObject("Wall");
BoxCollider3D wallCollider = new BoxCollider3D(new Vector3(10f, 4f, 1f), Vector3.Zero);
wall.AddComponent(wallCollider);
wallCollider.onCollision += det => Logger.Info("Game", $"{det.gameObject.name} hit the wall");

//Trigger, lets everything walk through, fires onTriggerEnter and onTriggerExit instead
GameObject checkpoint = new GameObject("Checkpoint");
BoxCollider3D checkpointCollider = new BoxCollider3D(new Vector3(2f, 3f, 2f), Vector3.Zero, isTrigger: true);
checkpoint.AddComponent(checkpointCollider);
checkpointCollider.onTriggerEnter += det => Logger.Info("Game", $"{det.gameObject.name} reached the checkpoint");

Creating Custom Colliders

Every method that actually defines a shape's behaviour is a public virtual, so you can inherit from Collider3D directly and build your own, the exact same way BoxCollider3D and SphereCollider3D do internally. Call the base constructor and override whichever of the five methods below your shape actually needs.

None of these five methods are required, the base implementations are safe no-ops and returns false or 0. Only override the ones your shape actually needs. A trigger only shape, for example, never needs CheckCollision.

CheckOverlap(Vector3 point) : only used for trigger Colliders. Return true if the given world space point is inside your shape. This is what drives onTriggerEnter, onTriggerStay and onTriggerExit.

CheckCollision(ref Vector3 objPos, Vector3 prevPos) : only used for solid, non-trigger Colliders. objPos is the Detector's current position, passed by reference. If it's penetrating your shape, push it back out by modifying prevPos directly.
prevPos, the Detector's position last frame, helps resolve edge cases like a point sitting exactly on your shape's center. Leave objPos untouched if there's no penetration.

GetBroadphaseRadius() : a bounding sphere radius around WorldCenter, used to decide which spatial hash grid cells your Collider gets inserted into. For example, the values for the SphereCollider3D are its radius multiplied by the highest scale of his GameObject's Vector3 scale, and for the BoxCollider3D it's a bounding sphere calculated with the collider size and the Transform scale.

GetBroadphaseRadius() is important, too small value can cause Detectors to not find the Collider even when they're within its range. If the shape is complex or inaccurate, prefer a larger radius value rather than one too small.


RayCast(Vector3 rayOrigin, Vector3 rayDirection, float maxDistance, out RaycastHit hit) : a ray intersection test against your shape. rayDirection is already normalized. Return true and fill hit with the intersection point, an outward facing normal, and the distance, only if it's within maxDistance. Otherwise return false with hit set to null.

DrawShapeDebug(Camera3D cam) : purely visual, called when the Collider is active and Scene3D.debugShowColliders is on. Use the static helpers on DebugDrawShapes3D( DrawBox, DrawSphere or DrawLine) to draw a wireframe of your shape in world space.

A custom floor collider 
public class FloorPlaneCollider3D : Collider3D
{
    //A large but finite radius, an actually infinite plane doesn't fit a cell based grid well
    const float broadphaseRadius = 500f;

    public FloorPlaneCollider3D(bool isTrigger = false, bool enabled = true) : base(isTrigger, enabled) { }

    //Checks if the point is inside the trigger or not (in this case, under the floor, no matter what the height is)
    public override bool CheckOverlap(Vector3 point)
    {
        return point.Y <= WorldCenter.Y;
    }

    //Checks if the point is inside the collider, and moves the object upwards if it's the case (collision)
    public override void CheckCollision(ref Vector3 objPos, Vector3 prevPos)
    {
        if (objPos.Y < WorldCenter.Y)
            objPos.Y = WorldCenter.Y;
    }

    //Returns a RayCast if the ray intersected with the floor
    public override bool RayCast(Vector3 rayOrigin, Vector3 rayDirection, float maxDistance, out RaycastHit hit)
    {
        hit = null;
        //Parallel to the plane, no meaningful hit
        if (MathF.Abs(rayDirection.Y) < 0.0001f) return false;

        float t = (WorldCenter.Y - rayOrigin.Y) / rayDirection.Y;
        if (t < 0f || t > maxDistance) return false;

        Vector3 point = rayOrigin + rayDirection * t;
        hit = new RaycastHit(point, Vector3.Up, t, this, rayOrigin, rayDirection);
        return true;
    }

    //Draws the box of the Collider in wireframe
    public override void DrawShapeDebug(Camera3D cam)
    {
        DebugDrawShapes3D.DrawBox(WorldCenter, new Vector3(broadphaseRadius, 0.05f, broadphaseRadius),
                Quaternion.Identity, cam, Color.Red);
    }

    public override float GetBroadphaseRadius() => broadphaseRadius;
}

Properties

Property Type Description
isTrigger bool Whether this collider fires trigger events instead of physically blocking Detectors, default false
CenterOffset Vector3 Local space offset from the GameObject's position, marks the collider dirty automatically when changed
enabled bool Whether this collider is enabled and participates in collision detection, marks the collider dirty automatically when changed, default true
WorldCenter Vector3 CenterOffset transformed into world space using the GameObject's Transform
gameObject GameObject The GameObject this collider is attached to
onCollision Action<CollisionDetector> Fired on a solid collider when it pushes a Detector out
onTriggerEnter Action<CollisionDetector> Fired on a trigger collider the frame a Detector enters it
onTriggerStay Action<CollisionDetector> Fired on a trigger collider every frame a Detector remains inside it
onTriggerExit Action<CollisionDetector> Fired on a trigger collider the frame a Detector leaves it
