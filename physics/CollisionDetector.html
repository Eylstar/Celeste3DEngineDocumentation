CollisionDetector

Class Component

CollisionDetector only experiences collisions and can't cause them. See the CollisionSystem page for the full picture of how it works together with Collider3D. Added to a GameObject like any other component with AddComponent(), it turns that GameObject into something that can be pushed by solid Colliders and notified about triggers.

A GameObject with only a Collider3D and no CollisionDetector is a static obstacle (or a trigger area), it blocks things but is never itself moved by the collision system. A GameObject with only a CollisionDetector and no Collider3D can be blocked by other things but doesn't block anything itself. Give it both if it needs to do both.

Basic CollisionDetector usage 
//A player pushed around by solid colliders, centered a bit above its feet
GameObject player = new GameObject("Player");
CollisionDetector detector = new CollisionDetector(distanceToCheck: 1.5f, offset: new Vector3(0f, 1f, 0f));
player.AddComponent(detector);
myScene.AddGameObject(player);

detector.onCollision += col => Logger.Info("Game", $"Bumped into {col.gameObject.name}");
detector.onTriggerEnter += col => Logger.Info("Game", $"Entered {col.gameObject.name}");

//Temporarily stop this detector from colliding with anything
detector.enabled = false;
Debug gizmos (the center and range spheres drawn when debugDrawCenter or debugDrawDistance are true) still show up for a disabled Detector, even though it no longer participates in any collision checks while enabled is false.

Collision Detector specific usages and limits

A CollisionDetector has no shape or radius of its own. distanceToCheck only decides how far it reaches to notice a Collider is nearby, it isn't used at all once the CheckCollision actually runs. The point that gets tested and pushed out is exactly detector.position, a single point in space.

This matters for example for anything with a camera attached. A single CollisionDetector centered on an FPS camera lets its center point sit against a wall, since that one point never technically penetrates it, but the camera's lens and near plane still clip straight through the wall's geometry. A common fix is surrounding the camera with several Detectors instead of one, offset slightly forward, back, left and right, so at least one of them catches the wall and pushes the whole GameObject away before the camera itself gets close enough to clip.

For complex physics simulations, you can also approximate them with multiple detectors on the same GameObject. For example, to make two cubes collide, you can add one BoxCollider and 8 CollisionDetector (one for every corner) each.

Since the ResolveCollisions only pushes objects and don't apply a real torque, the objects will only collide with each other and slide along their faces, not rotate with accurate physics.
Adding more CollisionDetector to the same GameObject has a negligeable cost in performance. The HashSet query is done once per object, not once per detector.

DistanceToCheck and Offset

distanceToCheck is the maximum distance allowed between this Detector's position and a Collider's actual surface before that Collider gets tested at all. It's checked precisely against each Collider's real shape, not just which grid cell it happens to be in. Set it too small and a Collider only a bit further away than the Detector's own size won't be detected. Set it too large and it will check more Colliders than it needs to every frame.

offset moves the actual detection point away from the GameObject's Transform position, in local space. Useful to place it at a character's feet for ground checks, or at chest height for wall pushing, rather than dead center of the model.

Multiple detectors on one GameObject 
//A small detector at the feet, for ground checks, and a wider one at chest height for pushing off walls
CollisionDetector feet = new CollisionDetector(distanceToCheck: 0.3f, offset: new Vector3(0f, 0.1f, 0f));
CollisionDetector chest = new CollisionDetector(distanceToCheck: 0.6f, offset: new Vector3(0f, 1.2f, 0f));

player.AddComponent(feet);
player.AddComponent(chest);

Constructors

Declaration Description
CollisionDetector(float distanceToCheck = 5f, Vector3 offset = default) Creates a new CollisionDetector

Properties

Property Type Description
enabled bool Whether this detector participates in collision detection, default true
distanceToCheck float How far this detector reaches to find Colliders, both for the broadphase query and the actual check
offset Vector3 Local space offset of the detection point from the GameObject's Transform position
debugDrawCenter bool Whether to draw a small debug sphere at the detector's position, default true
debugDrawDistance bool Whether to draw a debug sphere showing distanceToCheck, default false
gameObject GameObject The GameObject this detector is attached to
onCollision Action<Collider3D> Fired when a solid Collider pushes this detector out
onTriggerEnter Action<Collider3D> Fired the frame this detector enters a trigger Collider
onTriggerStay Action<Collider3D> Fired every frame this detector remains inside a trigger Collider
onTriggerExit Action<Collider3D> Fired the frame this detector leaves a trigger Collider
