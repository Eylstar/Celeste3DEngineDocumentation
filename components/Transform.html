Transform

Class

A Transform holds the position, rotation and scale of a GameObject in world space. Every GameObject owns exactly one Transform, accessible through GameObject.transform.

Rotation is stored internally as a Quaternion, but can be read and set using Euler angles in degrees for convenience. All rotation methods keep both representations in sync automatically.

The order of the components in RotationEuler and GetEuler() is (Pitch, Yaw, Roll), meaning X = Pitch, Y = Yaw, Z = Roll. Be careful when reading or constructing Euler values.

Since the Transform values cannot be changed by hand, you need to use the functions suchs as MoveBy(), SetPosition(), SetRotation() or Rotate() to update your object transform.

Basic Transform usage 
//Move a ball up and rotate it 90° around the Yaw axis
GameObject ball = scene.FindFirstByName("Ball");
ball.transform.MoveBy(new Vector3(0f, 5f, 0f));
ball.transform.Rotate(new Vector3(0f, 90f, 0f));

//Make an object look at the player
GameObject enemy = scene.FindFirstByName("Enemy");
enemy.transform.LookAt(player.transform.Position);

//Read back current values
Vector3 pos = ball.transform.Position;
Vector3 euler = ball.transform.RotationEuler;
Vector3 scale = ball.transform.Scale;

Constructors

Declaration Description
Transform() Default constructor, position is zero, rotation is identity, scale is one on all axes
Transform(Vector3 position, Vector3 rotationEuler = default) Creates a Transform at the given position with an optional rotation in Euler angles in degrees, scale defaults to one on all axes
Transform(Vector3 position, Quaternion rotation) Creates a Transform at the given position with the given rotation Quaternion, scale defaults to one on all axes
Transform(Vector3 position, Vector3 rotationEuler, Vector3 scale) Creates a Transform with position, rotation in Euler angles in degrees and scale explicitly set
Transform(Vector3 position, Quaternion rotation, Vector3 scale) Creates a Transform with position, rotation Quaternion and scale explicitly set

Properties

Property Type Description
Position Vector3 Position values in world space
Rotation Quaternion Rotation values in world space as a Quaternion
RotationEuler Vector3 Rotation values in world space as Euler angles in degrees
Scale Vector3 Scale value of the GameObject
Forward Vector3 Forward direction of the Transform
Up Vector3 Up direction of the Transform
Right Vector3 Right direction of the Transform

Methods

Method Return type Description
MoveBy(Vector3 delta) void Moves the transform by a delta in world space
SetPosition(Vector3 newPosition) void Sets the position of the transform in world space
SetRotation(Vector3 newRotationEuler) void Sets the rotation of the transform using Euler angles in degrees
SetRotation(Quaternion rotation) void Sets the rotation of the transform using a Quaternion
Rotate(Vector3 rotationToAdd) void Rotates the transform by adding to its current Euler angles in degrees
Rotate(Quaternion rotation) void Rotates the transform by multiplying its current rotation by a Quaternion
LookAt(Vector3 target) void Rotates the transform to look at a target point in world space
LookAt(Vector3 target, Vector3 upDirection) void Rotates the transform to look at a target point in world space with specified Up Vector
GetEuler() Vector3 Gets the current rotation as Euler angles in degrees
SetScale(Vector3 newScale) void Sets the scale of the GameObject
SetScale(float uniformScale) void Sets the scale of the GameObject uniformly on all axes
