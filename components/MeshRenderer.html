MeshRenderer

Class Component

The MeshRenderer is the Component used for rendering 3D models. It's the only Component a GameObject can hold a single instance of, and it's what allows a GameObject to actually show up in the scene.

Which constructor you use depends on your model format. Passing only a model name creates a GLB MeshRenderer (texture is embedded in the file), while passing a model name and a texture name creates an OBJ MeshRenderer (texture is loaded separately).

Prefer using GLB models over OBJ ones. They are easier to use, can hold multiple textures, and are way more optimized. OBJ and exports are better suited if you have a simple / single texture object who needs its texture changed at runtime with an external png.
The Format (OBJ/GLB) cannot be changed once the MeshRenderer is created.


The ModelLayer passed to the constructor decides where this model belongs in the scene : World for regular scenery, Foreground for elements rendered in front of everything else, HUD for screen-space elements, and Skybox, reserved for the scene's Skybox.

Each MeshRenderer also holds a Material instance, which controls how the Model's surface looks : its color, how it reacts to lighting, and whether it emits light of its own. If none is set, the Model uses the Engine's DefaultMaterial. Use GetMaterial() and SetMaterial() to read or change it.

Basic MeshRenderer usage 
//Creates a GLB MeshRenderer and adds it to a GameObject
GameObject rock = new GameObject("Rock");
rock.AddComponent(new MeshRenderer("rock"));

//Creates an OBJ MeshRenderer with a separate texture
GameObject crate = new GameObject("Crate");
crate.AddComponent(new MeshRenderer("crate", "crate_texture"));

//Changes the model and layer at runtime
MeshRenderer renderer = crate.GetComponent<MeshRenderer>();
renderer.ChangeModel("crate_broken");
renderer.ChangeLayer(ModelLayer.Foreground);

//Creates a new Material and assigns it to the MeshRenderer
Material mat = new Material();
mat.Shininess = 3f;
mat.tint = new Vector3(0.8f, 0.8f, 0.8f);
crate.GetComponent<MeshRenderer>().SetMaterial(mat);
Setting isVisible to false stops the Model from rendering, but it will still cast shadows if castsShadows is true. Use both together if you want a Model to be completely absent from the scene.

Layer Properties Details

The Layer of the object works a bit differently, depending if you're in IsHDMode or not (see Renderer3D), especially if you want to mix 3D rendering and Celeste base Rendering.

In non HD mode (or pixel art rendering) the World Layer draws objects beetween the stylegrounds and the Celeste rendering, and the Foreground above the Celeste rendering, under some additional Celeste visual effects.

In HD mode, World renders behind everything except the Skybox, including stylegrounds, and Foreground renders above eveything. This is due to IL hooking and 3D pipeline limitations.

HUD in both cases renders above everything else. This is useful if you want to display models in a set position of the screen. Instanciating an HUD model is done with Screen-space coordinates, adjusted for a 1920x1080 screen with Scene3D.AddHUDObject. Your screen resolution doesn't matter here, just use a 1920x1080 ratio (for example 960:540 will always be in the middle) and the Z value represents how close of the screen the object will be.

Creation of an HUD model 
//Create and place a compass in the bottom center of the screen
compass = new GameObject(new Vector3(960, 950, 180), Vector3.Zero, Vector3.One * 50f);
compass.AddComponent(new MeshRenderer("compassModel"));
mainScene.AddHUDObject(compass);
Scene3D.AddHUDObject automatically sets the Layer to HUD when the object is Added if a MeshRenderer was found (if not, it returns an error). The Layer still can be changed later at runtime.

And the Skybox Layer is only used for the Skybox. It's not recommended to use it for anything else.

Constructors

Declaration Description
MeshRenderer(string modelName, ModelLayer modelLayer = ModelLayer.World) Creates a new GLB MeshRenderer with the given model name
MeshRenderer(string modelName, string textureName, ModelLayer modelLayer = ModelLayer.World) Creates a new OBJ MeshRenderer with the given model and texture names
MeshRenderer(string modelName, Material mat, ModelLayer modelLayer = ModelLayer.World) Creates a new GLB MeshRenderer with the given model name, and sets the material
MeshRenderer(string modelName, string textureName, Material mat, ModelLayer modelLayer = ModelLayer.World) Creates a new OBJ MeshRenderer with the given model and texture names, and sets the material

Properties

Property Type Description
castsShadows bool Whether this Model casts shadows, default true
receivesShadows bool Whether this Model receives shadows, default true
isFrustumCulled bool Whether this Model should be automatically culled and not rendered when outside the frustum of the rendering camera, default true
isVisible bool Whether this Model is visible, setting this to false stops it from rendering, default true

Methods

Method Return type Description
ChangeTexture(string newTexturePath) void Changes the texture of this Model at runtime (only for OBJ models)
ChangeModel(string newModelPath) void Changes the model of this Model at runtime
ChangeLayer(ModelLayer newLayer) void Changes the layer of this Model at runtime
GetMaterial() Material Returns the Material of this Object
SetMaterial(Material mat) void Sets the material for this Model, passing null resets it to the DefaultMaterial
GetLayer() ModelLayer Returns the layer of this Model
GetFormat() ModelFormat Returns the format of this Model
