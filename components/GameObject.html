GameObject

Class

A GameObject is the most fundamental type to use in a Scene3D. It's the base class of everything that can be instantiated. It can represent anything including characters, scenery, lighting or even an invisible object like a manager running in the background. Every other instantiable object, such as Light or Skybox for example, all inherits GameObject

All GameObjects contains the same core elements : a Transform, and two strings for the Name and the Tag.

A new GameObject can be created like any variable type. it then needs to be added to the Scene3D with Scene3D.AddGameObject(). The object's variables values and components can be set and updated at any time. To remove a GameObject you can use GameObject.Destroy().

Destroying the GameObject removes it from the scene and all his references will return a null pointer. Always check if the object isn't destroyed with GameObject.IsDestroyed before using and getting references.
Basic GameObject creation and usage 
//Creates an object named Ball and adds it to the scene
GameObject ball = new GameObject("Ball");
myScene.AddGameObject(ball);

//Sets the tag of the ball (it can be anything) and disable it
ball.SetTag("Props");
ball.enabled = false;

//Destroy the Ball completely
ball.Destroy();

Life Cycle


The GameObject life cycle is important and consists of 5 steps : Added, Start, Update, Render and Removed. Every function in the object cycle will call the same function in every of its components (see the part below).

Added is called at the exact moment the GameObject is added to the scene with Scene3D.AddGameObject, regardless of if it's before or after the scene initialization itself. Use scene references with caution in Added, if they are not instantiated you will get a null reference.

Start will always be called after Added. It will be called at the scene initialization for objects added before it, and for objects added while the scene is running, Start is called one frame after.

Update and Render will be called by the scene same functions at the same time, only after Start is called on the object.

Removed will be called right after GameObject.Destroy is called.

To resume, Added at the moment the object is added, Start right after if the scene is started, and then Update and Render each frame after that.

If enabled is set to false, Start and Update functions of the object will not be called. Added and Destroy/Removed still works as intended.

Components

A GameObject by itself can't do much. To fully use your objects, you need to add Components to them.
There is three types of Components a GameObject can hold : a MeshRenderer, a Collider/CollisionDetector and any Behaviour inherited class.

The MeshRenderer is the only Component that can be present only once in a GameObject. (Adding another will simply override the previous one). It's mandatory to make the object be able to hold a 3D Mesh and display it in the scenery.

Collider and CollisionDetector components are used to make the object behave physically in the scenery (it doesn't need to have a MeshRenderer, for example for Triggers).
The CollisisonDetector is used for reacting to other Collider components of other objects in the scene, both Collide and Trigger type.

And finally, the Behaviour is a placeholder class in which anything can be done, by itself it doesn't do anything. This is where you're going to write all of your game logic.
A Behaviour contains the full Life Cycle (Added, Start, Update, Render and Removed) and any code you write inside of it will be called at the same time as the cycle of the GameObject. AudioSource and AnimationPlayer for example both inherits from Behaviour.

Any Component can be manipulated with the same functions. You can add any Component, remove them or get their references.

Components Usage 
GameObject ball = new();

//Adding a MeshRenderer with a variable and two BoxCollider3D to the ball 
MeshRenderer renderer = new MeshRenderer("ball");
ball.AddComponent<MeshRenderer>(renderer);
ball.AddComponent<BoxCollider3D>(new BoxCollider3D(Vector3.One, Vector3.Zero));
ball.AddComponent<BoxCollider3D>(new BoxCollider3D(Vector3.One * 2, Vector3.Zero));

//Get components references from the ball 
MeshRenderer rend = ball.GetComponent<MeshRenderer>();
List<BoxCollider3D> cols = ball.GetAllComponents<BoxCollider3D>();

//Remove the MeshRenderer and the first BoxCollider3D only from the ball 
ball.RemoveComponent<MeshRenderer>(renderer);
ball.RemoveFirstFoundComponent<BoxCollider3D>();

//If the ball still has Colliders, remove all of them 
if(ball.HasComponent<BoxCollider3D>())
    ball.RemoveAllComponents<BoxCollider3D>();

Default Shapes

DefaultCube, DefaultPlane and DefaultSphere are static properties that hand you a ready made GameObject, already carrying a MeshRenderer pointing at one of the Engine's bundled primitive shapes with a default texture. No modeling or importing, just a shape you can drop into a Scene immediately.

They're meant for prototyping and debugging. Blocking out a level's rough layout with cubes before the real art exists, marking a raycast hit point with a small sphere while you're testing collision, standing in a plane where a floor will eventually go...

Quick prototyping with default shapes 
//Block out a rough level layout before any real models exist
GameObject block = GameObject.DefaultCube;
block.transform.SetPosition(new Vector3(0f, 1f, 5f));
block.transform.SetScale(new Vector3(2f, 1f, 4f));
myScene.AddGameObject(block);

//Mark a point in space while debugging
GameObject marker = GameObject.DefaultSphere;
marker.transform.SetPosition(hit.Point);
marker.transform.SetScale(0.2f);
myScene.AddGameObject(marker);
Each of these is a get accessor, not a stored reference, every time you read GameObject.DefaultCube you get a brand new GameObject and MeshRenderer, not the same instance back. That's fine to call as often as you like, the underlying mesh geometry is still shared and cached the same way any other model is.

Constructors

Declaration Description
GameObject() Creates a GameObject with an empty name and a default Transform (position zero, no rotation, uniform scale of 1)
GameObject(string name) Creates a GameObject with the given name and a default Transform
GameObject(Transform transform, string name = "") Creates a GameObject using an existing Transform instance, with an optional name
GameObject(Vector3 position, Vector3 rotation, Vector3 scale, string name = "") Creates a GameObject with a new Transform built from the given position, rotation (Euler angles, degrees) and scale, with an optional name

Properties

Property Type Description
GetScene Scene3D Returns the Scene3D this GameObject currently belongs to, or null if it hasn't been added to a scene yet
enabled bool Whether this GameObject is active
IsDestroyed bool Whether this GameObject is destroyed. Getting references on a destroyed object will give you null reference exceptions.
name string The name of this GameObject
tag string The tag of this GameObject
transform Transform The Transform currently attached to this GameObject. Can only be set with SetTransform()
initialTransform Transform A copy of the Transform this GameObject had at the moment it was created
DefaultCube static GameObject Creates a default cube GameObject with a MeshRenderer component
DefaultPlane static GameObject Creates a default plane GameObject with a MeshRenderer component
DefaultSphere static GameObject Creates a default sphere GameObject with a MeshRenderer component

Methods

Method Return type Description
Destroy() void Destroys this GameObject and removes it from the scene. All references to it will return null afterwards
SetTransform(Transform t) void Replaces the Transform of this GameObject with the given one
SetName(string newName) void Sets the name of this GameObject
SetTag(string newTag) void Sets the tag of this GameObject
AddComponent<T>(T t) void Adds a component of type T to this GameObject. Supports MeshRenderer, Behaviour, Collider3D and CollisionDetector
RemoveComponent<T>(T t) void Removes the given component instance from this GameObject, if found
RemoveFirstFoundComponent<T>() void Removes the first component of type T found on this GameObject
RemoveAllComponents<T>() void Removes every component of type T from this GameObject
GetComponent<T>() T Returns the first component of type T attached to this GameObject, or null if none is found
GetAllComponents<T>() List<T> Returns every component of type T attached to this GameObject
HasComponent<T>() bool Returns whether this GameObject has at least one component of type T attached
GetPositionLastFrame() Vector3 Returns the world position this GameObject had at the end of the previous frame's Update
