Material

Class

Material holds the surface properties of a 3D model : its color, how it reacts to lighting, and whether it emits light of its own. Every MeshRenderer holds a Material, accessible through GetMaterial() and SetMaterial().

When isLit is true, DiffuseColor, SpecularColor and Shininess control how the Model reacts to the scene's lighting. When isLit is false, lighting is ignored and Color is used as a flat color.
In both cases, Color is the base albedo of your material.

If no Material is assigned to a MeshRenderer, the Engine's DefaultMaterial is used. It can be changed globally with SetDefaultMaterial().

Basic Material usage 
//Create a lit Material with a red diffuse color and set it on a MeshRenderer
Material mat = new Material();
mat.SetDiffuseColor(Color.Red);
mat.Shininess = 8f;
crate.GetComponent<MeshRenderer>().SetMaterial(mat);

//Create an unlit Material, colored using tint
Material unlitMat = new Material();
unlitMat.isLit = false;
unlitMat.tint = new Vector3(0.2f, 0.8f, 1f);

//Make an emissive Material
Material glowMat = new Material();
glowMat.EmissiveColor = Vector3.One;
glowMat.EmissiveIntensity = 2f;

//Change the Engine's DefaultMaterial for every Scene
Material.SetDefaultMaterial(mat);

Constructors

Declaration Description
Material() Creates a new Material with default values, lit, white diffuse and specular colors, no emissive

Properties

Property Type Description
Color Vector3 Albedo of the material
DiffuseColor Vector3 Color of the material under diffuse lighting
SpecularColor Vector3 Color of the material under specular lighting
Shininess float Shininess of the material, higher values result in smaller, sharper specular highlights
isLit bool Whether the material is affected by lighting
EmissiveColor Vector3 Emissive color of the material, the color it appears to emit, unaffected by lighting
EmissiveIntensity float Emissive intensity of the material, multiplies the emissive color

Methods

Method Return type Description
CopyFrom(Material mat) void Copies the values from another Material into this one
Clone() Material Creates a copy of this Material to prevent changes to the original when modifying the copy
SetDefaultMaterial(Material mat) static void Sets a new DefaultMaterial for the Engine, effective in all Scenes
SetDiffuseColor(Color color) void Sets the diffuse color of the material using a MonoGame Color
SetSpecularColor(Color color) void Sets the specular color of the material using a MonoGame Color
