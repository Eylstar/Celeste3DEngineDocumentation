AnimationPlayer

Class Inherits from Behaviour Component

AnimationPlayer is a Behaviour that plays skeletal animations on a skinned GLB model. It reads the animation clips and skin data embedded in the model file, and computes the bone matrices used to deform the mesh every frame.

Animation names passed to Play() and CrosseFade() come directly from the GLB file, the same names your modeling tool gave to each animation action. If a clip has no name in the file, it falls back to Anim_0, Anim_1, and so on, based on its index in the file.

AnimationPlayer only works with a GLB model that has a skin and animation data. The GameObject it's attached to needs a MeshRenderer already pointing to such a model.

The MeshRenderer must be added to the GameObject before the AnimationPlayer. Adding the MeshRenderer afterwards will leave the AnimationPlayer non-functional, with a warning.
Basic AnimationPlayer usage 
//Add the MeshRenderer first, then the AnimationPlayer
GameObject npc = new GameObject("Npc");
npc.AddComponent(new MeshRenderer("npc_rigged"));
AnimationPlayer anim = new AnimationPlayer();
npc.AddComponent(anim);
myScene.AddGameObject(npc);

//Play an animation once the object has started
anim.Play("Idle");

//Smoothly blend into a Walk animation over 0.25 seconds
anim.CrosseFade("Walk", 0.25f);

//Play a one-shot animation without looping
anim.Play("Jump", loop: false);

//Stop all animation playback
anim.Stop();
Calling CrosseFade() with the animation that is already playing, or already being blended toward, does nothing.

Constructors

Declaration Description
AnimationPlayer() Creates a new AnimationPlayer, requires a MeshRenderer pointing to a skinned GLB model on the same GameObject to function

Methods

Method Return type Description
Play(string animName, bool loop = true) void Starts playing the specified animation immediately from the beginning, with a hard cut and no blending, if loop is true the animation repeats indefinitely
CrosseFade(string toAnimName, float duration, bool loop = true) void Smoothly transitions from the currently playing animation to the specified animation over the given duration
Stop() void Stops the currently playing animation and clears any in-progress blend
IsPlaying bool Returns whether an animation is currently playing
