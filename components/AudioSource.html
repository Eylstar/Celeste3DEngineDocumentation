AudioSource

Class Inherits from Behaviour Component

AudioSource is a Behaviour component that lets a GameObject play a 3D positional sound effect. The sound follows the GameObject's Transform, so how loud it is and where it seems to come from depends on its position relative to the current AudioListener (see below).

Since AudioSource is a Behaviour, it's added to a GameObject like any other one, with AddComponent().

The played sound effect volume will also behave according to the Celeste's own SFX volume option, proportionally multiplied to the volume value of the effect. If you want to play a music instead (not always recommended, see AudioSource vs FMOD below), you can change this behaviour by setting useSFXVolumeSetting to false and use the music option value.

Sound files must be placed inside the audio folder configured for the EngineEntity and in the EnginePaths, and referenced without their extension. Both .wav and .ogg are supported.
Basic AudioSource usage 
//Add an AudioSource to a GameObject and load a sound
GameObject bell = new GameObject("Bell");
AudioSource source = new AudioSource();
bell.AddComponent(source);
source.LoadSound("bell_ring");

//Play it once
source.Play();

//Play it looped at half volume with Celeste music volume
source.loop = true;
source.volume = 0.5f;
source.useSFXVolumeSetting = false;
source.Play();

//Stop it early
source.Stop();

AudioListener

3D sounds are only meaningful relative to a listener, the point and orientation used to compute distance attenuation and panning. Every Scene3D has one AudioListener, which by default follows the position and orientation of the scene's rendering Camera.

This can be changed with Scene3D.ChangeAudioListenerObject() to make the listener follow any GameObject instead, for example the player character rather than the camera. Use Scene3D.ResetAudioListenerToCamera() to go back to the default behaviour.

AudioSource vs FMOD

AudioSource is better fitted for short, positional sound effects, a door creak, footsteps, an impact tied to a specific GameObject. It's not a replacement for a proper FMOD bank when it comes to music or long ambience. Both systems can be used simultaneously.

Sound files aren't streamed, the whole file gets decoded into memory the moment LoadSound() is called, and it stays cached for as long as the Engine is loaded, not just the current Scene. That's nothing for a two second effect, but several minutes of ambient music adds up fast, especially if more than one track gets loaded over a play session.

Using an AudioSource for one background, looping music is fine, but for actual complex music or long ambience, use a regular FMOD bank through Celeste's own audio system instead.

Constructors

Declaration Description
AudioSource() Creates a new AudioSource, no sound is loaded until LoadSound is called

Properties

Property Type Description
volume float The volume of the sound effect, from 0.0, silent, to 1.0, full volume
loop bool Whether the sound effect should loop when it reaches the end
useSFXVolumeSetting bool Whether the sound effect should use the Celeste SFX volume or the Music one
Changing volume while a sound is already playing takes effect immediately. Changing loop while a sound is already playing does not, it will only apply the next time Play() is called.

Methods

Method Return type Description
LoadSound(string path) void Loads a sound effect from the given path, the path should be inside the audio folder and without extension
Play() void Plays the loaded sound effect, if no sound effect is loaded this will log a warning, calling this while a sound is already playing restarts it
Stop() void Stops the currently playing sound effect, if any
