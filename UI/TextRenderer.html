TextRenderer

Class

TextRenderer is what actually draws text, it turns a TextData's content and style into pixels or geometry, depending on which type of UICanvas it ends up on. It's not a Component, it's an object you create and attach to a Canvas with AddTextRenderer().

TextRenderer implements IDisposable. The UICanvas disposes it for you when removed or cleared, but if you ever discard one without going through a Canvas, dispose it yourself to free its GPU buffers.

TextData and Styling

Every TextRenderer owns a TextData, through its public textData field. That's where the actual content, position and style live (see the TextData page for the full list).
Editing its properties directly changes what's on screen, each one marks this TextRenderer dirty automatically.
SetData() replaces the whole thing at once, useful if you're keeping reusable style presets and want to apply one entirely.

A single TextData can be shared across as many TextRenderers as you want. Every property change, including fontSize, notifies all of them at once. This makes it a convenient way to define a reusable style, a common look for every monster nameplate in a level for example, then tweak it in one place and have every TextRenderer using it update together.


Basic TextRenderer usage 
//Create a basic text "Hello"
TextRenderer label = new TextRenderer();
label.textData.content = "Hello";
label.textData.position = new Vector2(200f, 100f);
hud.AddTextRenderer(label);

//Create one TextData and reuse it for multiple TextRenderers
TextData titleData = new TextData();

titleData.content = "Level Complete";
titleData.fontSize = 32;
titleData.position = new Vector2(960, 100);
titleData.align = TextAlignment.Center;

TextRenderer title1 = new TextRenderer(titleData);
TextRenderer title2 = new TextRenderer(titleData);

Fonts

A CustomFont is referenced by its name, file name without the extension. It has to already be loaded : either the Engine's built in default font, Renogare, or one found in your mod's configured fonts folder. See EnginePaths for how that gets set up.

Every constructor that doesn't take a font name explicitly uses Renogare (default Celeste font).
SetFont() swaps the font on an existing TextRenderer.

Changing font at runtime 
TextRenderer label = new TextRenderer("PixelFont");
...
//Switches to a different loaded font
label.SetFont("HandwrittenFont");
If the font name passed to a constructor or to SetFont() isn't found, it doesn't fail or throw, it silently falls back to Renogare instead, logging an error. This includes SetFont() specifically, a typo in the font name there switches the TextRenderer to the default font rather than leaving its previous font untouched. Double check your font names if text unexpectedly shows up in the default font.

Multi Line Text and Alignment

Splitting content with \n produces multiple lines, each one is positioned and aligned independently according to align, Left, Center or Right, but rotation is applied to the whole block at once around its overall center, not to each line individually.

Multi line, aligned, rotated text 
TextRenderer sign = new TextRenderer();
sign.textData.content = "Danger\nDo Not Enter";
sign.textData.align = TextAlignment.Center;
sign.textData.rotation = 15f;

Moving a World Canvas

Instead of manually moving every component inside a WorldSpace Canvas, updating its Transform moves everything alongside.

Nameplate above an enemy 
//A WorldSpace Canvas that follows the enemy, positioned above its head
UICanvas nameplateCanvas = new UICanvas { canvasType = CanvasType.WorldSpace };
nameplateCanvas.transform.SetPosition(enemy.transform.Position + new Vector3(0f, 2.5f, 0f));

TextRenderer nameLabel = new TextRenderer();
nameLabel.textData.content = "Slime";
nameplateCanvas.AddTextRenderer(nameLabel);

//Each frame, keep the canvas following the enemy
nameplateCanvas.transform.SetPosition(enemy.transform.Position + new Vector3(0f, 2.5f, 0f));

Constructors

Declaration Description
TextRenderer() Creates a TextRenderer using the default font, Renogare, and a fresh default TextData
TextRenderer(TextData data) Creates a TextRenderer using the default font and the given TextData
TextRenderer(string fontName) Creates a TextRenderer using the given font and a fresh default TextData
TextRenderer(string fontName, TextData data) Creates a TextRenderer using the given font and the given TextData

Properties

Property Type Description
textData TextData The content and style this TextRenderer draws, edit it directly or replace entirely it with SetData

Methods

Method Return type Description
SetFont(string fontName) void Switches to a different loaded font, falls back to the default font if the name isn't found
SetData(TextData data) void Replaces this TextRenderer's TextData entirely
Dispose() void Releases the GPU buffers used for WorldSpace rendering
