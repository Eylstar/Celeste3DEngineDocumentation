UICanvas

Class Inherits from GameObject

UICanvas is a container for UI content, TextRenderer and UISprite instances live on one. you can see the UICanvas as a 2D placeholder in which you can place graphic elements. It inherits from GameObject, so it's added to a Scene like anything else, with AddGameObject().

A Scene can hold as many Canvases as you want, and each one is independently either Overlay or WorldSpace, set through canvasType. This single choice changes almost everything about how its content behaves.

Overlay vs WorldSpace

An Overlay Canvas draws straight to the screen, on top of everything (the 3D scene and the rest of Celeste's own rendering). Its content isn't positioned in a real resolution either, it uses a fixed 1920 by 1080 reference space that gets uniformly scaled and centered to fit whatever the actual window size is.
This means (960, 540) is always the center of the screen, and the same coordinates look the same relative to the screen no matter what resolution the player is running at, you never have to do that math yourself. The Canvas's own Transform is completely ignored for this type, only the position, scale and rotation of each individual TextRenderer or UISprite on it matters.

A WorldSpace Canvas is the opposite, it's a flat panel that actually exists in the 3D scene, anchored at the Canvas GameObject's own Transform. Its Right and Up directions become the panel's local axes, and every piece of content on it is positioned as a 2D offset along those axes, scaled by the Canvas's own uniform scale.
It's rendered as real geometry alongside your models, which means it respects depth. A wall or a character standing between the camera and a WorldSpace Canvas will hide it, the same way it would hide a model.

Moving, rotating or scaling a WorldSpace Canvas's Transform marks every TextRenderer and UISprite on it dirty at once, they all rebuild together next frame. This makes the Canvas itself a convenient handle to move an entire group of UI content together, a whole floating panel above an enemy, for example, without touching each piece individually.


Use Overlay for anything that belongs to the player's screen, HUD elements, menus, anything that should always be visible.
Use WorldSpace for anything that belongs to the scene itself, a floating nameplate above a character, a sign, a damage number that appears where something happened.

Your WorldSpace Canvas will behave with the models geometry only if it's in the same Layer. All models layer are by default on "World" layer and not foreground, so does the Canvas. If you rendered models in foreground, or want the world canvas to render above everything in your scene while being not in Overlay mode, you can change isRendererInForeground.

Adding Content

A Canvas doesn't create its content for you, you build a TextRenderer or a UISprite yourself and attach it with AddTextRenderer() or AddUISprite(). ClearCanvas() removes and disposes everything at once, useful when tearing down a whole piece of UI.

An Overlay HUD and a WorldSpace nameplate 
//An Overlay canvas, screen space, always visible, with a score text and a heart icon
UICanvas hud = new UICanvas();

TextRenderer scoreText = new TextRenderer();
scoreText.textData.content = "Score: 0";
scoreText.textData.position = new Vector2(100f, 60f);
hud.AddTextRenderer(scoreText);

UISprite heartIcon = new UISprite("icons/heart", new Vector2(60f, 60f));
hud.AddUISprite(heartIcon);

//A WorldSpace canvas, anchored above an enemy in the scene
UICanvas nameplateCanvas = new UICanvas();
nameplateCanvas.canvasType = CanvasType.WorldSpace;
nameplateCanvas.transform.SetPosition(enemy.transform.Position + new Vector3(0f, 2.5f, 0f));

TextRenderer nameLabel = new TextRenderer();
nameLabel.textData.content = "Slime";
nameLabel.textData.fontSize = 24;
nameplateCanvas.AddTextRenderer(nameLabel);

UISprite skullIcon = new UISprite("icons/skull", new Vector2(0f, -40f));
nameplateCanvas.AddUISprite(skullIcon);

Constructor

Declaration Description
UICanvas() Creates an empty Canvas, overlay by default

Properties

Property Type Description
canvasType CanvasType Whether this Canvas draws as screen space Overlay or as a panel in the 3D scene. Default Overlay
isRendererInForeground bool Only active if the canvasType is WorldSpace. Decides wether this should be drawn in the world or foreground render target. Default false

Methods

Method Return type Description
AddTextRenderer(TextRenderer textRenderer) void Adds a TextRenderer to the Canvas
AddUISprite(UISprite sprite) void Adds a UISprite to the Canvas
RemoveTextRenderer(TextRenderer textRenderer) void Removes a TextRenderer from the Canvas
RemoveUISprite(UISprite sprite) void Removes a UISprite from the Canvas
ClearCanvas() void Removes and disposes every TextRenderer and UISprite on the Canvas
GetTextRenderers() IReadOnlyList<TextRenderer> Returns a ReadOnly List of all the TextRenderers on this Canvas
GetUISprites() IReadOnlyList<UISprite> Returns a ReadOnly List of all the UISprites on this Canvas
