UISprite

Class

UISprite draws a single image on a UICanvas. It can be an icon, a portrait, a background panel. Like TextRenderer, it works in both Overlay and WorldSpace, add it to a Canvas with AddUISprite().

Its texture is always loaded from your mod's custom textures folder, EnginePaths.CustomTexturesPath.

Basic UISprite usage 
//An icon in the corner of the screen
UISprite icon = new UISprite("icons/heart", new Vector2(80f, 80f));
hud.AddUISprite(icon);

//Changing it later
icon.SetScale(new Vector2(1.5f, 1.5f));
icon.SetRotation(45f);
icon.SetAlpha(0.5f);
pixelPerUnit only affects WorldSpace sprites, it's ignored entirely in Overlay, where a sprite always draws at its texture's native pixel size, times Scale.
There's no visibility flag. To hide a UISprite without removing it from its Canvas, set its alpha to 0 with SetAlpha().

Constructors

Declaration Description
UISprite(string texturePath) Creates a UISprite from a texture, positioned at zero
UISprite(string texturePath, Vector2 position, Vector2 scale, Color? color = null, float alpha = 1f, float rotation = 0f) Creates a UISprite with position, scale, color, alpha and rotation set upfront

Properties

Property Type Description
Position readonly Vector2 Current position
Scale readonly Vector2 Current scale
Color readonly Color Current color tint, default white
Alpha readonly float Current alpha transparency, 0 is fully transparent, 1 is fully opaque
Rotation readonly float Current rotation in degrees
pixelPerUnit readonly float WorldSpace only, how many texture pixels equal one world unit, default 200

Methods

Method Return type Description
SetPosition(Vector2 newPos) void Sets the position
SetScale(Vector2 newScale) void Sets the scale
SetColor(Color newColor) void Sets the color
SetAlpha(float newAlpha) void Sets the alpha transparency
SetRotation(float newRotation) void Sets the rotation in degrees
