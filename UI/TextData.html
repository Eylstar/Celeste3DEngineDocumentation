TextData

Class

TextData holds everything about how a piece of text looks and where it sits, content, position, color, size, alignment, shadow. Every TextRenderer owns one, through its public textData field. It's a plain data object, build one, tweak its properties, or swap a TextRenderer's entire style at once with TextRenderer.SetData().

Changing any property marks the owning TextRenderer dirty automatically, so it rebuilds and reflects the change next frame.

A shadow only actually draws if all three of shadow is true, shadowColor has a non zero alpha, and shadowOffset is not exactly 0. Setting shadowOffset to 0 disables the shadow entirely, it doesn't draw one directly behind the text.

Constructors

Declaration Description
TextData() Creates a new TextData with default values

Properties

Property Type Description
content string The text to display, split it with \n for multiple lines
position Vector2 Position of the text, in screen space for an Overlay Canvas or local Canvas space for WorldSpace, default zero
fontSize int Size the font is rasterized at, changing it regenerates the underlying font at that size, default 16
scale float Extra uniform scale applied on top of fontSize, cheap but blurrier if scaled up significantly, default 1
mainColor Color Main color of the text, default white
alpha float Alpha transparency, 0 is fully transparent, 1 is fully opaque, default 1
shadow bool Whether to draw a shadow behind the text, default true
shadowColor Color Color of the shadow, default black
shadowOffset float Offset of the shadow in pixels, default 4
spacing float Extra spacing between characters in pixels, default 0
lineHeightMult float Multiplier applied to the space between lines on multi line text, default 1
align TextAlignment Horizontal alignment of each line relative to the others, Left, Center or Right, default Center
rotation float Rotation of the whole text block in degrees, default 0
pixelsPerUnit int WorldSpace only, how many pixels of the rasterized font equal one world unit, higher values make the text smaller and crisper, tune it together with fontSize, default 300
visible bool Whether the text is drawn at all, default true
