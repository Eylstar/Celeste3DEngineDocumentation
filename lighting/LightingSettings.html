LightingSettings

Class

LightingSettings holds everything that applies to a Scene as a whole such as ambient light, directional light, shadow quality, and fog. Every Scene3D has one, you can get it with Scene3D.GetLightingSettings() and reapply your changes with Scene3D.SetLightingSettings().

Getting and applying LightingSettings 
//Get the current LightingSettings and reassign it to the scene
LightingSettings settings = myScene.GetLightingSettings();
settings.fogDensity = 0.05f;
myScene.SetLightingSettings(settings);

Ambient Light

AmbientLightColor is a flat color added to every lit surface in the Scene, no matter which way it's facing or how far it is from any light. It doesn't come from a direction and it never casts shadows, think of it as the light bouncing around a room even in places no direct light reaches.

It's mostly there to stop the unlit side of your models from going completely black. A dim grey ambient keeps shadowed areas readable, a near-black ambient gives you deep, dramatic shadows, and a bright ambient flattens your lighting out and makes the scene look more evenly lit overall.

Directional Light

The directional light is the Scene's sun, or moon. Unlike PointLight and ConeLight, it isn't a GameObject, it doesn't have a position, and it shines with the same direction and strength across the entire Scene, exactly like sunlight does at the scale of a level. There's only ever one, controlled through LightingSettings.

DirectionalLightDirection is the direction the light travels, not the direction pointing back at it. The default, (-1, -1, -1), points down and to the side, like sunlight coming from above.

Setting this vector by hand works, but it's easier to use SetDirectionalLightRotation(), which takes Euler angles in degrees, ordered as Pitch, Yaw, Roll, the same convention Transform uses.

Directional Light examples 
//Warm low sun
settings.DirectionalLightColor = new Vector3(1f, 0.8f, 0.6f);
settings.SetDirectionalLightRotation(new Vector3(40f, -30f, 0f));

//Pale moonlight
settings.DirectionalLightColor = new Vector3(0.6f, 0.65f, 0.8f);
settings.SetDirectionalLightRotation(new Vector3(75f, 0f, 0f));

//Straight down direction
settings.DirectionalLightDirection = new Vector3(0f, -1f, 0f);

Shadows

The Engine has two separate shadow systems that don't share any settings besides the near plane, bias and strength below. The directional light uses a global shadow map, and each shadow casting ConeLight gets its own individual shadow map. PointLight never casts shadows.

Directional shadows - The shadows casted by the unique global directional light, toggled with DirectionalLightCastsShadows. shadowMapResolution controls the quality of the shadow map. shadowFarPlane stops the shadows for rendering beyond a certain point. You can increase this value to render farther shadows, but as this decrease the texel density in the shadow map, the quality will go lower (it's not recommended to go over 4096 for the shadowMapResolution).

Spot light shadows - each ConeLight with CastsShadows set to true gets its own shadow map, sized directly by spotLightShadowMapResolution. Its far plane is the light's own range, not shadowFarPlane.

Shadows Tuning - shadowBias pushes shadows slightly away from the surfaces that cast them. Too low and you get shadow acne, flickering self-shadowed patterns on lit surfaces, too high and shadows start detaching from their objects.
shadowStrength controls how dark shadowed areas end up, 0 makes shadows invisible, 1 makes them fully dark.
shadowSoftness tweaks how blur the edge of the shadows will be. A value of 0 will results in very rough and aliased shadows, increasing it increases the blur effect. A value too high and the shadows will stop looking accurate at all. Recommended values are beetween 0 and 15.

Fog

There are two independent fog layers, that stack together. fogColor is shared by both.

fogDensity controls regular distance fog, the further something is from the camera, the more it fades into fogColor. This is the classic depth fog, useful for hiding draw distance limits or just adding a sense of scale to a large scene.

heightFogDensity and heightFogStart control a second fog layer based on world height instead of camera distance. Anything below heightFogStart fades into fogColor the lower it is, regardless of how close it is to the camera. This is what you'd use for something like ground mist.

Set both densities to 0 to disable fog entirely.

Skybox and HUD layer models ignore fog automatically, only World and Foreground layer models are affected.
Fog examples 
//Light atmospheric fog
settings.fogColor = new Vector3(0.6f, 0.7f, 0.8f);
settings.fogDensity = 0.02f;
settings.heightFogDensity = 0f;

//Thick ground mist, clear above it
settings.fogColor = new Vector3(0.7f, 0.75f, 0.7f);
settings.fogDensity = 0.01f;
settings.heightFogStart = 2f;
settings.heightFogDensity = 0.15f;

//No fog at all
settings.fogDensity = 0f;
settings.heightFogDensity = 0f;

Properties

Property Type Description
AmbientLightColor Vector3 Flat color applied to every lit surface regardless of light direction or distance, default a dim grey Color(0.2f, 0.2f, 0.2f)
DirectionalLightColor Vector3 Color of the scene's directional light, default 1
DirectionalLightDirection Vector3 Direction the directional light travels in, not the direction pointing back to it, default down and to the side
DirectionalLightCastsShadows bool Whether the directional light casts shadows, default true
shadowMapResolution int Base resolution of the directional light's shadow map, default 4096
spotLightShadowMapResolution int Actual resolution of each ConeLight's individual shadow map, default 1024
maxShadowedLights float The maximum number of ConeLight that can cast shadows at once.
shadowNearPlane float Near clip plane used when rendering shadow maps, default 0.1
shadowFarPlane float Far clip plane for the directional light shadows, ConeLights use their own range instead, default 60
shadowStrength float How dark shadowed areas appear, 0 is invisible, 1 is fully dark, default 1
shadowSoftness float How far the shadow's soft edge samples spread, in shadow map texels. 0 gives a hard edge, higher values blur it further. Default 1.5
shadowBias float Small depth offset applied to shadow maps to reduce shadow acne, default 0.001
fogDensity float Density of the regular distance fog, default 0.035
heightFogDensity float Density of the height based fog, default 0.06
heightFogStart float World height below which the height fog starts applying, default 0
fogColor Vector3 Color both fog types fade into, default a pale blue

Methods

Method Return type Description
SetDirectionalLightRotation(Vector3 eulerDegrees) void Sets DirectionalLightDirection from Euler angles in degrees, ordered as Pitch, Yaw, Roll, same convention as Transform
