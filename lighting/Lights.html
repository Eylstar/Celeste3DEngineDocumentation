Light

Class Abstract Inherits from GameObject

Light is the abstract base class for every light source in the Scene, it inherits from GameObject. You never create a Light directly, you create either a PointLight or a ConeLight, the two types the Engine currently supports.

Lights are invisible on their own, they only affect MeshRenderers whose Material has isLit set to true. Adding a Light to the Scene with AddGameObject() is all it takes to make it active, unlike a Camera it doesn't need to be set as anything, it registers and unregisters itself with the Renderer automatically.

Basic Light usage 
//A warm point light
PointLight lamp = new PointLight(new Vector3(0f, 3f, 0f), Color.OrangeRed, 1.2f, 8f);
myScene.AddGameObject(lamp);

//A cone light aimed at the ground, casting shadows
ConeLight spot = new ConeLight(new Vector3(0f, 6f, 0f), Color.White, 1.5f, 15f, 45f);
spot.transform.LookAt(Vector3.Zero);
spot.CastsShadows = true;
myScene.AddGameObject(spot);

Shared Properties

These three properties come from Light itself, both PointLight and ConeLight have them.

Property Type Description
color Color Color of the light, default white
intensity float Brightness multiplier of the light, default 1
range float How far the light reaches, used both for its falloff and for culling it against distant models, default 10

PointLight

Class Inherits from Light

A PointLight shines outward in every direction from its position, like a bare lightbulb. It doesn't currently support casting shadows.

Declaration Description
PointLight(Vector3 position, Color color, float intensity = 1f, float range = 10f) Creates a PointLight at the given position

ConeLight

Class Inherits from Light

A ConeLight shines in a cone shape along its forward direction, like a spotlight or a flashlight. Its constructor only takes a position, so to aim it somewhere you need to set its rotation afterwards, with transform.LookAt() or transform.SetRotation().

Angle is the full width of the cone, in degrees.
SpotFalloffcontrols how much the light fades out gradually toward the edge of the cone. 0 = no falloff, 1 = full falloff.
ShadowDistanceAttenuationControls how quickly the shadow's edge softens with distance. 1 = normal, higher values = faster fade, default at 1.5. This is additive with the global shadow softness parameter.

CastsShadows only takes effect if the Scene has fewer shadow casting spot lights than its LightingSettings.maxShadowedLights allows. Beyond that limit, the ConeLight still lights the scene normally, it just won't cast a shadow.
Declaration Description
ConeLight(Vector3 position, Color color, float intensity, float range, float angle) Creates a ConeLight at the given position, all parameters are required
Property Type Description
Angle float Full width of the light's cone, in degrees
SpotFalloff float Controls how gradually the light fades toward the edge of the cone
ShadowDistanceAttenuation float Controls how quickly the shadow's edge softens with distance. 1 = normal, higher values = faster fade
CastsShadows bool Whether this light casts a shadow, default false
