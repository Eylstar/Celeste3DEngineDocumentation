EngineEntity

Class Inherits from Monocle.Entity

The EngineEntity class is the one who will load the whole Engine. It represents the bridge beetween the Celeste/Monocle pipeline and this one and it's a Celeste Entity, placeable in Lönn. Having this Entity placed in a room will allow you to use the 3D Engine.

The EngineEntity class handles the 3D scenes loading and unloading. Once the EngineEntity finishes to load his core data, it will call an OnEngineLoad event. Use it to start loading your mod content and code, and to create your main 3D Scene.
Also, don't forget to Unsubscribe from the event, with Removed and SceneEnd.

To load a Scene3D create it first, then pass it to EngineEntity.LoadScene. It will automatrically unload the previous loaded Scene3D if there was any.

Multiple 3DScene can be created, setuped and stored as variables in your code. This can be useful to manage for exemple mutliple rooms by loading each scene when transitionning.
Scene loading and unloading 
// Engine Event Subscription
public MyCustomModBuilder(EntityData data, Vector2 offset) : base(data.Position + offset)
{
    EngineEntity.OnEngineLoad += CreateMainScene;
}

void CreateMainScene(EngineEntity entity, Scene celesteScene)
{
    // Mod content loading | Scene creation
    Scene3D myscene = new Scene3D();
    ---

    // Load the Scene in the EngineEntity
    EngineEntity.LoadScene(myscene);
}

// Unsubscribe
public override void Removed(Scene s)
{
    base.Removed(s);
    EngineEntity.OnEngineLoad -= CreateMainScene;
}

public override void SceneEnd(Scene s)
{
    base.SceneEnd(s);
    EngineEntity.OnEngineLoad -= CreateMainScene;
}


By default, the engine should not be persistent across rooms, since it relies on a Celeste Entity to work. To solve this, the EngineEntity contains a workflow to save and load itself its state across rooms and celeste levels quit/reload.
Persistent state is at false by default, you can change it with SetPersistence.
See Engine Persistence and EngineCallbacks pages for more information.

Constructors

Declaration Description
EngineEntity(EntityData data, Vector2 offset) : base(data.Position + offset) Base Celeste Entity constructor. Don't use it
EngineEntity(string models, string textures, string exports, string fonts, string audio, bool persistence) Creates a new EngineEntity with the specified paths and persistence. Useful for runtime EngineEntity creation. Strings can be empty if not used, see EnginePaths.

Methods

Method Return Type Description
LoadScene static void Loads a new 3D scene, unloading the previous one if it exists
UnloadCurrentScene static void Unloads the current active 3D scene
GetCurrentScene static Scene3D Gets the current active 3D scene
GetCelesteScene static Scene Gets the Celeste Scene the Engine is in
SetPersistence static void Sets whether the EngineEntity should persist across rooms

Events

Declaration Parameters Passed Description
OnEngineLoad EngineEntity, Scene Event invoked when the EngineEntity is added to a scene. Passes with it itself and the Celeste Scene
Since EngineEntity inherits from Monocle.Entity, it also inherits forced public methods such as its constructor and methods like Added, Update etc. Don't use them unless you're absolutely sure what you're doing.
