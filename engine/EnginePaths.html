EnginePaths

Class Static

EnginePaths is where the Engine keeps track of which folders your content lives in, models, textures, exports, fonts and audio. Every system that loads an asset by name (MeshRenderer, AudioSource, the font loader, etc) starts reading from EnginePaths to figure out where to actually look for it.

You don't usually set these paths yourself, EngineEntity already does it for you from what you filled in when placing it in Lönn.

Default vs Custom Paths

There are two separate sets of paths. The default ones point at the Engine's own bundled assets, its default textures, exports and fonts, shipped with the Engine itself, not your mod. These are fixed and read only, exposed through DefaultTexturesPath, DefaultExportsPath, DefaultModelsPath and DefaultFontsPath.

The custom ones point at your own mod's content folders, wherever you keep your models, textures, exports, fonts and audio. These start out empty and are what EngineEntity fills in for you, through modelsPath, texturesPath, exportsPath, fontsPath and audioPath in Lönn.

How Paths Get Set

When an EngineEntity is placed in a room, its constructor reads the five path attributes you filled in and passes them straight to EnginePaths, before the Engine has even finished loading.

This is also why EngineEntity's constructor has an internal only overload that skips Lönn entirely, taking the same five paths directly as strings, meant for mods that construct an EngineEntity in code instead of placing one in the map editor.

You can pass an empty string to any property if you're 100% sure the folder is never gonna be used.


If you need to change any of these paths later, at runtime, after the Engine is already running, that's what SetAllPaths() and the individual setters are for.

Changing paths at runtime 
//Point the Engine at a different textures folder for this mod
EnginePaths.SetTexturesPath("Graphics/3DEngine/Models/MyMap/Eylstar");

//Set everything at once, with empty fields for Textures and Exports (not useful when using GLB models)
string strBase = "Graphics/3DEngine/";
EnginePaths.SetAllPaths(strBase+"Models/MyMap/Eylstar", "", "", strBase+"Fonts/MyMap/Eylstar",
                strBase+"Audio/MyMap/Eylstar");

Fonts Specific Loading

Models, textures, exports and audio are all loaded lazily, on demand, the first time something actually asks for a specific one by name. Fonts don't work that way. The moment a fonts path is set, whether through EngineEntity's own startup or through SetFontsPath() or SetAllPaths(), the Engine immediately scans that entire folder and loads every .ttf and .otf file it finds in it, indexed by file name.

This is why SetFontsPath() is the only individual setter with a side effect, setting it doesn't just remember the path, it triggers loading right away. The other four setters, SetModelsPath(), SetTexturesPath(), SetExportsPath() and SetAudioPath(), only update the stored path, nothing gets loaded until something actually references a file from it.

Properties

Property Type Description
DefaultTexturesPath string The Engine's own default textures folder
DefaultModelsPath string The Engine's own default models folder
DefaultExportsPath string The Engine's own default exports folder
DefaultFontsPath string The Engine's own default fonts folder
CustomModelsPath string The currently configured folder for your mod's models
CustomTexturesPath string The currently configured folder for your mod's textures
CustomExportsPath string The currently configured folder for your mod's exported models
CustomFontsPath string The currently configured folder for your mod's fonts
CustomAudioPath string The currently configured folder for your mod's audio

Methods

Method Return type Description
SetAllPaths(string models, string textures, string exports, string fonts, string audio) static void Sets every custom path at once, and loads fonts from the fonts path if it's not empty
SetModelsPath(string path) static void Sets the custom models path
SetTexturesPath(string path) static void Sets the custom textures path
SetExportsPath(string path) static void Sets the custom exports path
SetFontsPath(string path) static void Sets the custom fonts path, and immediately loads every font found in it
SetAudioPath(string path) static void Sets the custom audio path
ResetPaths() static void Resets every custom path back to empty, called automatically when the Engine unloads
